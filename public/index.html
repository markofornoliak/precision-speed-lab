Measurement methodology

Download. Фактически полученные байты делятся на browser wall-clock duration основного прогона после connection warm-up.

Upload. Основная скорость считается по общему monotonic receive-window на measurement server — от первого принятого байта до последнего. Время получения JSON-ответа не занижает результат.

Latency. Это HTTP RTT. P50/P90/P95/P99 считаются по успешным idle probes. TCP может скрывать L3 packet loss, поэтому здесь показан именно HTTP probe loss.

Loaded latency. Метрика публикуется только при достаточном числе успешных probes и приемлемой доле timeout. Bufferbloat — фактическая добавка loaded P50 к idle P50.

Variation. Коэффициент вариации steady-state throughput samples; меньше — стабильнее. Это не искусственный stability score.

Aggregation. Медиана повторных прогонов; при ≥5 прогонах грубые run-level выбросы могут исключаться MAD-фильтром. 95% CI — percentile bootstrap для медианы.
