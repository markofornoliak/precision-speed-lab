METHOD

Что именно измеряется

Throughput. Фактически полученные/принятые байты делятся на wall-clock duration основного прогона после connection warm-up.

Latency. HTTP RTT; P50/P90/P95/P99 считаются по успешным idle probes. TCP может скрывать реальный L3 packet loss, поэтому интерфейс показывает только HTTP probe loss.

Jitter. Среднее абсолютное изменение соседних RTT. Stability. Коэффициент вариации throughput samples, без искусственного «score».

Aggregation. Медиана повторных прогонов; при ≥5 прогонах грубые run-level выбросы могут исключаться MAD-фильтром. 95% CI — percentile bootstrap для медианы.
